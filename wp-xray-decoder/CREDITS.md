# Dental X-ray Decoder: files for 911dentist.org

Staging files for the WordPress page. This branch is not deployed to app.911dentist.org.

- `dental-xray-decoder-wordpress-block.html`: the page as one Custom HTML block. `{{XRD_IMG_…}}` placeholders are replaced with Media Library URLs when it is uploaded.
